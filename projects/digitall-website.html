PROJECT 04 / SELECTED WORK

DIGIT.all Website Redesign

A responsive website redesign for DIGIT.all, a student tech organization at The College of New Jersey, created alongside my ongoing webmaster responsibilities.

HTMLCSSJavaScriptGitHub Pages

Overview

As the DIGIT.all Webmaster and an E-Board member, I help maintain the organization’s GitHub-hosted site and work on a refreshed website experience. The new site lives in a separate repository so the existing club website can stay available during review and updates.

What I worked on

  • Designed a mobile-friendly organization site with sections for the club, events, leadership, and ways to get involved.
  • Structured event and E-Board content in editable data files, separating semester updates from page layout.
  • Built interactive event details and team profiles with keyboard-accessible dialogs and fallbacks when a flyer or headshot is not available.
  • Used GitHub repositories and GitHub Pages for source control, publishing, and an eventual handoff to future club webmasters.

What I learned

The practical challenge is maintaining a site for a real student organization: officer information and event dates change, so content needs to be easy to update without redesigning the entire page. The new website is a separate redesign project rather than a claim that the original site has already been replaced.

Project context

Club project / ongoing. The new website repository is public; the existing club site remains separate.
