PROJECT 05 / SELECTED WORK

Order Tracker: SQL & Flask Coursework

A database-systems exercise centered on managing customers, products, orders, and order items with SQL and Python query definitions.

SQLSQLitePythonFlask Coursework

Overview

In CSC 315 Database Systems, I worked on the data layer for an Order Tracker web-application exercise. The work includes the relational schema, sample records, SQL joins, and query definitions used by a provided Flask-based application.

What I worked on

  • Defined Customer, Product, Order_, and Order_Item tables with keys and foreign-key relationships.
  • Added sample products, customers, orders, and quantities to test the structure.
  • Used joins and an aggregated VIEW_ORDER_LIST view to calculate order item counts and totals.
  • Wrote Python SQL statements for listing, inserting, editing, updating, and deleting products, customers, orders, and order items.

What I learned

The important part of this project was connecting relational design with the operations an application needs. I worked with table relationships, CRUD queries, joins, and a summary view instead of treating each SQL statement as a stand-alone exercise.

Project context

Academic database/Flask integration exercise. The SQL and query definitions are documented; a fully tested, independently deployed web app is not claimed here.
