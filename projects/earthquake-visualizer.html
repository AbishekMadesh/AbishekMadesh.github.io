USGS Earthquake Data Visualizer

A C++ data structures project that organizes and visualizes real-world earthquake data from the USGS.

C++Binary Search TreesBRIDGES

Overview

I used earthquake data from the U.S. Geological Survey as the dataset for a binary search tree visualization project. Each earthquake record could include magnitude, location, timestamp, and geographic coordinates.

What it does

  • Organized earthquake records in a binary search tree using magnitude as the key.
  • Used recursive tree operations to work with the stored earthquake information.
  • Presented the data using the BRIDGES visualization platform.
  • Explored how data structure choices affect the way information is organized and displayed.

Technical experience

The project combined foundational data structures with real-world data. It gave me experience with recursive programming and translating structured information into something easier to inspect visually.
