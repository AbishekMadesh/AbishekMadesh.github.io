PROJECT 01 / SELECTED WORK

Unix Shell

A command-line shell built in C to explore how Unix programs start, run, and communicate with the operating system.

CLinux / UnixProcesses

Overview

For this systems programming project, I developed a Unix-style command-line shell in C. The goal was to go beyond writing a program that runs commands and work directly with process management and shell features.

What it does

  • Execute commands using process creation and program execution through fork(), execvp(), and waitpid().
  • Support directory navigation and command history.
  • Handle standard input/output redirection and pipelines.
  • Support background command execution.

Technical experience

The project involved using Unix system calls to coordinate processes and command behavior. Implementing the features helped me connect operating systems concepts from class with actual C code.
