What I built

For CSC 220, I wrote a Java program that takes a text file specifying the grid size and starting live cells. It asks how many iterations to display, advances the grid one generation at a time, and draws each step with the StdDraw library.

Implementation details

  • Read a grid's dimensions and cell states from a plain-text configuration file using Scanner.
  • Count each cell's eight possible neighbors while checking row and column boundaries.
  • Compute the next generation in a separate 2D array, so updates do not interfere with neighboring cells during the same step.
  • Draw live and dead cells using StdDraw and let the user run another configuration without restarting the program.

Original submission and demo

I recovered GameOfLifeFinal.java, configuration files including Glider, Blinker, Beacon, Toad and Pulsar, and two screenshots from the submitted project ZIP. The demo above applies the same neighbor-count and survival/birth rules with browser JavaScript so visitors can interact with it without installing Java.

What I learned

This project helped me practice file input, nested loops, array bounds, program state, and the difference between reading the current generation and writing the next one. It also showed me how relatively simple local rules can produce interesting patterns over time.

Project context

CSC 220 academic Java project (Fall 2024). Original submission verified in the TCNJ Canvas archive. The public interactive browser demo is an adaptation, not the original compiled program or its source code.
